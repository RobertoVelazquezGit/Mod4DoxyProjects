Detailed Description

Stores portfolio assets and covariance data and calculates portfolio risk.

Note
Portfolio optimization currently assigns equal weights, ignoring target returns and constraints. Frontier generation repeats this allocation for each requested point rather than computing an efficient frontier.

double FinancialEngineering::PortfolioOptimizer::calculatePortfolioRisk ( const std::map< std::string, double > & weights)

Calculates risk as the square root of the weighted portfolio variance.

Parameters
weightsAsset weights; missing registered assets receive zero weight
Returns
sqrt(max(0, w^T * covarianceMatrix * w)), or zero if matrix dimensions do not match the number of registered assets
Note
Weights for unregistered assets are ignored. Weights are not normalized, and the matrix is not checked for symmetry or positive semidefiniteness.
