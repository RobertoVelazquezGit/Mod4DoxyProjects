Detailed Description

StatisticsCalculator provides statistical analysis capabilities for data sets.

This class manages a collection of numeric values and can calculate various statistical measures such as mean, minimum, and maximum values.

Usage Pattern:

  1. Create StatisticsCalculator instance
  2. Add data values using addValue()
  3. Calculate statistics using calculation methods
  4. Clear data when ready to analyze a new set

Example: StatisticsCalculator stats; stats.addValue(10.0); stats.addValue(20.0); double mean = stats.calculateMean(); // Returns 15.0
